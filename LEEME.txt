PUBLICAR GRATIS CON GITHUB PAGES
1. Crea una cuenta en https://github.com si no tienes una.
2. Crea un repositorio público llamado tres-erre-web.
3. Sube index.html, styles.css, script.js y este LEEME.txt a la raíz del repositorio.
4. Abre Settings > Pages.
5. En Build and deployment, selecciona Deploy from a branch; branch main y folder /(root), luego Save.
6. Espera la publicación. GitHub mostrará la dirección pública en esa sección.
